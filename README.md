# Помощник загрузки (Download Helper)

GUI-приложение для загрузки потокового видео с помощью [N_m3u8DL-RE](https://github.com/nilaoda/N_m3u8DL-RE).

Пользователь копирует команду запуска из Telegram-бота, вставляет в приложение, настраивает имя файла и место сохранения, запускает загрузку. Поддерживается сохранение на локальный диск и в S3-совместимое хранилище.

---

## Требования

### Обязательные внешние инструменты

Все три утилиты должны находиться **в одной папке с приложением** (exe) или **в системном PATH**.

| Инструмент | Назначение | Ссылка |
|---|---|---|
| **N_m3u8DL-RE** | Загрузчик HLS/DASH потоков | [github.com/nilaoda/N_m3u8DL-RE/releases](https://github.com/nilaoda/N_m3u8DL-RE/releases) |
| **ffmpeg** | Мультиплексирование видео/аудио | [ffmpeg.org/download.html](https://ffmpeg.org/download.html) или [github.com/BtbN/FFmpeg-Builds/releases](https://github.com/BtbN/FFmpeg-Builds/releases) |
| **mp4decrypt** | Расшифровка защищённого контента (Bento4) | [bento4.com/downloads](https://www.bento4.com/downloads/) или [github.com/nichengjian0729/bento4_mirror/releases](https://github.com/nichengjian0729/bento4_mirror/releases) |

При запуске загрузки приложение автоматически проверяет наличие всех трёх утилит и выводит результат в логи. Если какая-то утилита не найдена — загрузка не начнётся.

### Python-зависимости

```
PyQt6 >= 6.5
boto3 >= 1.28
Unidecode >= 1.3
```

Установка:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Сборка в exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "DownloadHelper" main.py
```

Готовый файл появится в папке `dist/`. Положите рядом с ним `N_m3u8DL-RE`, `ffmpeg` и `mp4decrypt`.

## Функционал

### Получение команды

Отправьте **System Log (JSON)** боту [@kinpro_bot](https://t.me/kinpro_bot) в Telegram. Бот вернёт готовую команду для N_m3u8DL-RE.

### Вкладка «Новая задача»

#### Разбор команды
- Вставьте команду в текстовое поле
- Нажмите **«Разобрать команду»** — приложение извлечёт URL, имя файла и параметры

#### Имя файла
- Поле заполняется автоматически после разбора команды
- **«Нормализовать»** — транслитерирует кириллицу в латиницу, заменяет пробелы и спецсимволы на подчёркивания (`Тестовое Видео` → `Testovoe_Video`)

#### Место сохранения
- **Локально** — выбор папки через **«Обзор...»**. Последняя папка запоминается между сеансами
- **S3** — указывается путь в бакете. Кнопка **«Настройки»** открывает диалог S3-подключения:
  - Адрес (Endpoint)
  - Регион
  - Бакет
  - Ключ доступа / Секретный ключ
  - Кнопка **«Проверить подключение»** — проверяет доступность бакета
- При S3 файл сначала скачивается во временную локальную папку, затем отправляется в хранилище
- **«Удалить локальную копию после загрузки в S3»** — удаляет временный файл после успешной отправки

#### Очередь задач
- **«Добавить в очередь»** — добавляет задачу в очередь без запуска
- **«Скачать»** — запускает последовательное выполнение всей очереди. Если очередь пуста, запускает текущую задачу
- **«Остановить»** — прерывает загрузку и очищает очередь

#### Повторы при ошибке
- Поле **«Повторы при ошибке»** (0–10, по умолчанию 2) — количество автоматических повторных попыток при ошибке загрузки

#### Прогресс и логи
- Прогресс-бар с процентом, скоростью и оставшимся временем
- Панель логов с полным выводом N_m3u8DL-RE в реальном времени

#### Проверка свободного места
- Перед каждой загрузкой проверяется наличие минимум 500 МБ свободного места. При недостатке — задача пропускается

### Вкладка «История»

Таблица всех задач с колонками:
- **Имя** — название файла
- **Статус** — Ожидание / Загрузка / Отправка в S3 / Готово / Ошибка
- **Дата** — дата создания
- **Назначение** — Локально или S3

Кнопки:
- **«Показать логи»** — отображает логи выбранной задачи
- **«Повторить загрузку»** — переносит команду обратно во вкладку «Новая задача»
- **«Удалить»** — удаляет задачу из истории

### Справка

Кнопка **«?»** в правом верхнем углу окна открывает встроенное руководство пользователя.

## Хранение данных

Все данные хранятся в `~/.downloader_helper/`:

| Файл | Описание |
|---|---|
| `config.json` | Настройки: пути сохранения, параметры S3 |
| `tasks.db` | История задач (SQLite) |

```
Downloader/
├── main.py                        # Точка входа
├── requirements.txt
├── README.md
├── app/
│   ├── main_window.py             # Главное окно (вкладки: Новая задача / История)
│   ├── widgets/
│   │   ├── command_input.py       # Поле ввода команды + кнопка «Разобрать»
│   │   ├── file_name_edit.py      # Редактор имени + кнопка «Нормализовать»
│   │   ├── destination_panel.py   # Переключатель Локально / S3
│   │   ├── progress_panel.py      # Прогресс-бар загрузки
│   │   ├── task_list.py           # Таблица истории задач
│   │   └── log_panel.py           # Панель логов
│   ├── dialogs/
│   │   ├── s3_config_dialog.py    # Настройки S3 подключения
│   │   └── help_dialog.py         # Справка / руководство пользователя
│   └── core/
│       ├── command_parser.py      # Парсинг команды N_m3u8DL-RE
│       ├── normalizer.py          # Нормализация имени файла
│       ├── downloader.py          # QProcess обёртка для N_m3u8DL-RE
│       ├── s3_uploader.py         # QThread + boto3 загрузка в S3
│       ├── task_manager.py        # Управление задачами + история (SQLite)
│       └── config.py              # JSON конфиг
```
