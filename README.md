# Помощник загрузки (Download Helper)

GUI-приложение для загрузки потокового видео с помощью [N_m3u8DL-RE](https://github.com/nilaoda/N_m3u8DL-RE).

Пользователь копирует команду запуска из Telegram-бота, вставляет в приложение, настраивает имя файла и место сохранения, запускает загрузку. Поддерживается сохранение на локальный диск и в S3-совместимое хранилище.

---

## Требования

### Обязательные внешние инструменты

Все три утилиты должны находиться **в одной папке с приложением** (exe) или **в системном PATH**.

| Инструмент | Назначение | Ссылка |
|---|---|---|
| **N_m3u8DL-RE** | Загрузчик HLS/DASH потоков | [github.com/nilaoda/N_m3u8DL-RE/releases](https://github.com/nilaoda/N_m3u8DL-RE/releases) |
| **ffmpeg** | Мультиплексирование видео/аудио | [ffmpeg.org/download.html](https://ffmpeg.org/download.html) или [github.com/BtbN/FFmpeg-Builds/releases](https://github.com/BtbN/FFmpeg-Builds/releases) |
| **mp4decrypt** | Расшифровка защищённого контента (Bento4) | [bento4.com/downloads](https://www.bento4.com/downloads/) или [github.com/nichengjian0729/bento4_mirror/releases](https://github.com/nichengjian0729/bento4_mirror/releases) |

При запуске загрузки приложение автоматически проверяет наличие всех трёх утилит и выводит результат в логи. Если какая-то утилита не найдена — загрузка не начнётся.

### Python-зависимости

```
PyQt6 >= 6.5
boto3 >= 1.28
Unidecode >= 1.3
```

Установка:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Сборка в exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "DownloadHelper" --version-file version_info.txt --noupx main.py
```

Готовый файл появится в папке `dist/`. Положите рядом с ним `N_m3u8DL-RE`, `ffmpeg` и `mp4decrypt`.

## Функционал

### Получение команды

Отправьте **System Log (JSON)** боту [@kinpro_bot](https://t.me/kinpro_bot) в Telegram. Бот вернёт готовую команду для N_m3u8DL-RE.

### Вкладка «Новая задача»

#### Разбор команды
- Вставьте команду в текстовое поле
- Нажмите **«Разобрать команду»** — приложение извлечёт URL, имя файла и параметры
- При вставке через Ctrl+V команда разбирается автоматически

#### Имя файла
- Поле заполняется автоматически после разбора команды
- **«Нормализовать»** — транслитерирует кириллицу в латиницу, заменяет пробелы и спецсимволы на подчёркивания (`Тестовое Видео` → `Testovoe_Video`)

#### Место сохранения
- **Локально** — выбор папки через **«Обзор...»**. Последняя папка запоминается между сеансами
- **S3** — укажите путь в бакете. Поддерживается несколько профилей S3, переключение через выпадающий список. Кнопка **«Настройки»** открывает менеджер профилей:
  - Создание, переименование, удаление профилей
  - Для каждого профиля: адрес (endpoint), регион, бакет, ключ доступа, секретный ключ
  - Кнопка **«Проверить подключение»** — проверяет доступность бакета
- При S3 файл сначала скачивается в локальную папку (указанную в поле «Локально»), затем отправляется в хранилище
- **«Удалить локальную копию после загрузки в S3»** — удаляет файл после успешной отправки

> **Важно:** путь для загрузки **не должен находиться** в папках облачных хранилищ (OneDrive, Dropbox, Google Drive). Облачная синхронизация блокирует файлы во время записи, что приводит к ошибкам N_m3u8DL-RE. Используйте обычную локальную папку, например `C:\Downloads` или `D:\Video`.

#### Очередь задач
- **«Добавить в очередь»** — добавляет задачу в очередь без запуска. Кнопка доступна даже во время загрузки
- **«Скачать»** — запускает последовательное выполнение всей очереди. Если очередь пуста, запускает текущую задачу
- **«Отменить»** — прерывает текущую загрузку, очищает очередь и удаляет частично скачанные файлы
- Раскрывающаяся секция **«▶ Очередь (N)»** показывает содержимое очереди с возможностью удалить отдельные элементы или очистить всю очередь

#### Повторы при ошибке
- Поле **«Повторы при ошибке»** (0–10, по умолчанию 2) — количество автоматических повторных попыток при ошибке загрузки

#### Прогресс и логи
- Прогресс-бар с процентом, скоростью и оставшимся временем
- При загрузке нескольких потоков (видео, аудио, субтитры) отображается прогресс текущего активного потока
- Панель логов с выводом N_m3u8DL-RE в реальном времени
- Кнопки **«Копировать»** и **«Сохранить»** позволяют скопировать лог в буфер обмена или сохранить в файл

#### Проверка свободного места
- Перед каждой загрузкой проверяется наличие минимум 500 МБ свободного места. При недостатке — задача пропускается

### Авто-режим

Галочка **«Авто-режим»** в верхней части окна включает мониторинг буфера обмена:

1. Настройте место сохранения (Локально или S3, путь, профиль)
2. Включите **«Авто-режим»**
3. Скопируйте команду N_m3u8DL-RE откуда угодно (Ctrl+C)
4. Приложение автоматически:
   - Вставит и распарсит команду
   - Нормализует имя файла (если включена **«Авто-нормализация имени»**)
   - Начнёт загрузку или добавит в очередь (если загрузка уже идёт)

При срабатывании показывается системное уведомление (toast), чтобы можно было работать с приложением в свёрнутом виде.

Реагирует **только** на текст, содержащий «N_m3u8DL-RE» — обычное копирование не вызовет срабатывания.

---

### Уведомления

Приложение показывает системные уведомления (Windows toast) при:
- Завершении очереди загрузок
- Ошибке загрузки (после всех повторных попыток)
- Ошибке отправки в S3
- Срабатывании авто-режима (добавление/запуск задачи)

---

### Вкладка «История»

Таблица всех задач с колонками:
- **Имя** — название файла
- **Статус** — Ожидание / Загрузка / Отправка в S3 / Готово / Ошибка
- **Дата** — дата создания
- **Назначение** — Локально или S3

Кнопки:
- **«Показать логи»** — отображает логи выбранной задачи (с кнопками «Копировать» и «Сохранить»)
- **«Повторить загрузку»** — переносит команду обратно во вкладку «Новая задача»
- **«Удалить»** — удаляет задачу из истории

### Справка

Кнопка **«?»** в правом верхнем углу окна открывает встроенное руководство пользователя.

## Хранение данных

Все данные хранятся в `~/.downloader_helper/`:

| Файл | Описание |
|---|---|
| `config.json` | Настройки: пути сохранения, S3-профили |
| `tasks.db` | История задач (SQLite) |

│       ├── downloader.py          # QProcess обёртка для N_m3u8DL-RE
